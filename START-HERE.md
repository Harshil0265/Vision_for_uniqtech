# 🚀 START THE APP

## Run this ONE command:

```bash
npm run dev
```

This starts BOTH servers:
- Frontend (Vite) on http://localhost:5173
- Backend (API) on http://localhost:3000

## ⚠️ IMPORTANT: Keep this terminal window open!

Both servers run together. You'll see:
- **[VITE]** messages in cyan (frontend)
- **[API]** messages in magenta (backend)

## Open your browser:
http://localhost:5173

---

## If you get network errors when inviting members:

1. Check the terminal - both **[VITE]** and **[API]** should be running
2. If only [VITE] is running, stop it (Ctrl+C) and run `npm run dev` again
3. Make sure you see: `[API] [Vision] Server listening on port 3000`

---

## Need to restart?

Press `Ctrl+C` to stop both servers, then run `npm run dev` again.
